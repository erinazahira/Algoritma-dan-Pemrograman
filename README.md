# Simple Savings Management CLI

## Features ✨

* **User Authentication:** A simple login system to secure access.
* **Multiple Savings Accounts:** Manage funds in three distinct categories:
    * Emergency Fund
    * General Savings
    * Education Fund
* **Add & Withdraw Funds:** Easily deposit or withdraw money from any account.
* **Balance Inquiry:** Check the current balance of all savings accounts at a glance.
* **Transaction History:** View a summary of total income (deposits) and expenses (withdrawals) for each account.
* **Data Visualization:**
    * **Pie Chart:** See a percentage breakdown of your total savings distribution.
    * **Bar Chart:** Compare the total deposits and withdrawals for each savings account.

---

## Technologies Used 🛠️

* **Python:** The core programming language.
* **Matplotlib:** For generating the pie and bar charts.
* **NumPy:** To assist with data handling for the charts.
